Settings

Configure AI features and app preferences

🎨 Appearance

Pick a theme and your accent color. Saved on this device.

🤖 AI Provider

Powers the AI Workout Assistant & breakdowns. Pick a provider, paste its key. Stored locally only. Gemini & Groq have generous free tiers.

🍽 Meals AI

Powers meal calorie estimates. Can be a different provider than your workout AI. Uses the key saved above for whichever provider you pick. Groq is great here.

Meal photo identification always uses Gemini (the only one that reads images).

🎥 YouTube Clips (optional)

For embedded exercise video clips. Get a key at console.cloud.google.com → create project → enable "YouTube Data API v3" → Credentials → API key. Free: ~100 searches/day.

📦 Data Management

All data is stored in your browser's localStorage. Export to back it up.
